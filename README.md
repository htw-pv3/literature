# Literature

## Description
This repository contains literature about the "PV3 - Solaranlagen und -kraftwerke" lecture at HTW-Berlin.
It contains cheat sheets for the different software tools used during the course.

## Additional Information

### Included Resources and Literature:
* **Software:** Contains metadata for the software we work with (BibTeX entry: `references.bib`).
* **Git:** Version control software that enables collaborative work on a project. This section contains tutorials and commands.
* **Python:** An open-source programming language that is easy to learn and suitable for numerous purposes.
* **PV for Engineers:** Information and literature on setting up PV systems.
